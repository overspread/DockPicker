# DockPicker 1.0.1

DockPicker 是一个 macOS 菜单栏工具，用于控制**当前正在运行的应用**是否显示在原生 Dock 中。

首个正式版已发布。它通过未公开的 LaunchServices 通知实现；Apple 可能会在未来 macOS 更新中改变该行为，不同应用的兼容性也可能不同。

## 功能

- 搜索当前正在运行的普通应用。
- 按**全部**、**显示中**、**已隐藏**筛选列表。
- 显示应用图标、进程 ID 和显示/隐藏数量。
- 切换应用的 Dock 图标；在可用时通过辅助功能核验实际结果。
- 退出时保持已隐藏状态（菜单另有单独的 **恢复并退出**）。
- 恢复失败时取消退出，错误留在面板；操作进行中点退出会给提示。
- 按运行列表与原生 Dock 实况回收陈旧记录；读不到 Dock 时不再判定为“全部已隐藏”。

运行时方案只能控制正在运行的应用；未运行的应用不会出现在列表中。

## 兼容性

已在 macOS 27.2.1（build 26B131，Apple Silicon）本地验证。应用包声明的最低版本是 macOS 27.0；其他 macOS 版本和 Intel Mac 未经测试。

**未来 macOS 更新可能导致本工具失效或行为变化。** 该通知机制未公开，Apple 随时可能修改或移除相关行为。系统更新后，请先确认隐藏功能仍然有效。

**不同应用的兼容性可能不同。** 应用可能忽略显示请求、重新显示 Dock 图标，或在最小化窗口、Spaces、App Exposé、全屏窗口等场景表现不同。长期使用前，请对每个目标应用分别测试。

## 使用注意

该通知不是公开的“单图标可见性 API”。目标进程会继续以正常 activation policy 运行，但 Dock 可能更新其内部的最小化窗口、Spaces、App Exposé 和拖拽状态记录。

独立测试应用已通过显示/隐藏往返、相同 PID 检查、窗口输入、激活、菜单命令、全屏切换和额外窗口检查。维护者也在本机进行过实际使用测试，未注意到副作用；但这不能保证每个应用或工作流都不受影响。对照环境中原生最小化操作未正常响应，因此最小化兼容性**未验证**。

DockPicker 会在当前会话中首次隐藏每个应用前单独确认。请先测试非关键应用。如行为异常，请使用**全部恢复**。目标应用或 Dock 重启后，图标可能重新出现。没有辅助功能权限时，应用会显示保存的选择而不是已核验的 Dock 状态；此时点击列表上方的 **全部 / 显示中 / 已隐藏** 会自动提示开启该权限。

请勿在未经测试的情况下将其用于关键工作。聊天、代理、开发和生产关键应用可能有不同表现。本项目没有自动修改微信或任何其他已安装的目标应用。

## 权限

辅助功能权限仅用于读取原生 Dock 图标以核验状态，点击筛选控件时会自动检查并按需提示开启：

**系统设置 → 隐私与安全性 → 辅助功能**

隐藏操作不需要管理员密码、App 管理权限、目标应用包写入权限、目标应用签名变更或钥匙串访问。

## 发布

版本：**1.0.1**。该版本已在本地构建并验证。源码使用本地 Git 管理；发布或推送到远程仓库是另一个单独且明确的操作。

应用包版本为 `1.0.1`（build `2`）。

```sh
make build
open build/DockPicker.app
```

本地构建默认使用固定的自签名证书 **DockPicker Code Signing**，构建配置按证书指纹选择身份，不再使用随程序内容变化的 ad-hoc 签名。请始终保留并复用同一证书和私钥，同时保持应用标识 `org.dockpicker.app` 不变；切换到这张证书后需要重新授予一次辅助功能权限，后续更新通常可沿用授权。

本机使用 DockPicker 专用的独立签名钥匙串。它与本地解锁文件均保存在 `~/Library/Application Support/DockPicker/Signing/`，目录仅当前用户可访问；构建会自动解锁该钥匙串并签名，无需修改系统证书信任设置。私钥和解锁文件不包含在源码仓库或分享给用户的应用包中；公开证书会随应用的代码签名提供。发布者应安全备份该目录中的证书和私钥，换电脑时导入原身份；重新创建同名证书不能延续原身份。

其他开发者需自行准备代码签名身份。使用默认钥匙串中的证书时，可执行 `make build CODESIGN_IDENTITY="自己的证书名称或指纹" CODESIGN_KEYCHAIN=`；使用独立钥匙串时可覆写 `CODESIGN_KEYCHAIN` 和 `CODESIGN_PASSWORD_FILE`。默认身份或钥匙串不可用时构建会报错，不会静默退回临时签名。每次 `make build` 都会签名并核验，即使源码没有变化。

自签名版本可以免费分享，但没有 Apple Developer ID 和公证。接收者首次打开可能需要在“系统设置 → 隐私与安全性”中允许打开，再手动授予辅助功能权限；后续下载的新版本也可能出现安全提示。接收者无需导入发布者的证书或私钥。若以后采用 Developer ID 分发，可另行配置签名、公证流程。本仓库不包含预构建二进制。

## 项目安全

- 不要在本项目中编辑或重签名目标应用包。
- 不要向仓库添加应用 `Info.plist` 备份、私有应用数据、含用户数据的截图、签名密钥或证书。
- LaunchServices 行为应视为未公开且与系统版本相关。
- 应用包中的 `Resources/Info.plist` 使用中立标识符 `org.dockpicker.app`。
